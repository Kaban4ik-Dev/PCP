# Исходный код для лабораторных работ по предмету "Параллельное и конвейерное программирование".

## Инструкция для версии с Intel OneAPI
Версия кода, использующая Intel OneAPI, доступна только для Microsoft Visual Studio 2022.\
Для работы необходимо наличие GPU или CPU с интегрированной графикой Intel.\
В случае, если имеется только CPU Intel без интегрированной графики, программа запустится, но особых различий в производительности ожидать не стоит.
### Для запуска необходимо:
1. Установить Microsoft Visual Studio 2022.
2. Установить Intel OneAPI: Base Toolkit с официального сайта Intel. Минимально необходим только компилятор DPC++. Рекомендуется выбрать все опции в установщике, для обеспечения корректной работы профайлера.
3. Установить драйвер разработки (Intel Graphics Driver (DCH) for OneAPI) с официального сайта Intel.\
**Внимание:** драйвер индивидуален для каждого графического устройства Intel - выбирайте подходящий под ваше устройство. При установке драйвера необходимо выбрать все опции, включая обновление встроенного драйвера, если оно предлагается. Работоспособность программы проверялась на драйвере: Intel Arc Iris Xe Graphics - Windows DCH Driver.
4. Открыть выбранное решение в MSVS 2022 из директории вида `labN_one_api`, где N - номер лабораторной работы.
5. Собрать проект, используя **только** `Release` конфигурацию. Если собрать проект в `Debug` конфигурации, компилятор не применит оптимизации, из-за чего работа графического устройства будет гораздо медленне, чем CPU и в разы медленне, чем работа того же графического устройства при сборке с `Release` конфигурацией.

### Возможные проблемы с кодом
1. Компилятор Intel помечает все строки, содержащие кириллицу как предупреждения о некорректных символах. Несмотря на это, строки остаются корректными и выводятся правильно, если установить нужную локализацию.
